# Results & Artifacts Directory

This directory stores all experimental outputs, figures, evaluation metrics, model checkpoints, and sample forecast series generated across the **Traffic Speed Forecasting and Signal Control Simulation** project.

---

## Directory Structure

```text
results/
├── figures/               # 28 publication-grade visualization plots
├── metrics/               # 20 tabular metric CSV files and PyTorch model state
└── predictions/           # Held-out sample sensor forecast time series
```

## 2. Evaluation Metrics & Artifacts (`results/metrics/`)

Contains reproducible benchmark scores, adjacency weights, and model checkpoints:

* **`metr_la_model_comparison.csv`**: Master benchmark table reporting MAE, RMSE, MAPE (%), and valid target sample sizes across all 4 models, all 4 horizons, and all 3 time periods (All, Peak, Off-Peak).
* **`metr_la_baseline_metrics.csv` & `metr_la_baseline_period_metrics.csv`**: Detailed metrics for Persistence and Random Forest.
* **`metr_la_xgboost_metrics.csv` & `metr_la_xgboost_period_metrics.csv`**: Performance logs for Pooled XGBoost.
* **`metr_la_gat_metrics.csv` & `metr_la_gat_training_history.csv`**: Epoch-by-epoch loss, validation MSE, and test horizon metrics for GAT.
* **`metr_la_gat_state_dict.pt`**: Serialized PyTorch model weights for the trained Graph Attention Network.
* **`metr_la_distance_adjacency.csv`**: Symmetrized 207 × 207 Gaussian distance adjacency matrix ($threshold = 0.1$).
* **`simulated_signal_policy_metrics.csv`**: Time-step queue records, arrival rates, and delay metrics for the signal simulation.
* **`traffic_data_quality.csv` & `graph_data_quality.csv`**: Sensor counts, timestamp alignment, and completeness summaries.
* **`metr-la_sample_sensor_analysis.csv` & `pems-bay_sample_sensor_analysis.csv`**: Empirical distribution, speed percentiles, and persistence errors for arbitrary inspected sensors.

## 3. Held-out Forecasts (`results/predictions/`)

Stores test-split sample predictions used by the Streamlit dashboard for real-time visualization:

* `metr_la_random_forest_sample_sensor.csv`: Actual vs. predicted speed for Random Forest.
* `metr_la_xgboost_sample_sensor.csv`: Actual vs. multi-horizon predicted speeds for Pooled XGBoost.
* `metr_la_gat_sample_sensor.csv`: Actual vs. GAT multi-horizon predictions.
